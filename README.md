# ToDoリスト基本機能

単一ブラウザ内で動作する ToDo リストアプリです。HTML、CSS、バニラ JavaScript で実装し、
`localStorage` へ状態を保存します。

## 主なコマンド

- `npm install`: 開発用依存の導入
- `npm run dev`: ローカルサーバー起動
- `npm run test:unit`: 単体テスト実行
- `npm run test:e2e`: E2E テスト実行
- `npm test`: 単体テストと E2E テストを連続実行

## ドキュメント

- 仕様: `specs/001-todo-list-core/spec.md`
- 計画: `specs/001-todo-list-core/plan.md`
- タスク: `specs/001-todo-list-core/tasks.md`
