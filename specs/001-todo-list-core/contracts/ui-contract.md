# UI 契約: ToDoリスト基本機能

## 1. 画面構成

単一画面内に以下の要素を持つ。

| 領域 | 必須 | 内容 |
|------|------|------|
| アプリ見出し | 必須 | アプリ名または用途が分かるタイトル |
| タスク追加フォーム | 必須 | タスク名入力欄と追加実行ボタン |
| フィルタ切替 | 必須 | `すべて`、`未完了`、`完了済み` の切替 UI |
| タスクリスト | 必須 | 各 ToDo の内容、登録日時、状態、削除操作 |
| 空状態表示 | 必須 | 対象タスクが 0 件のときの案内 |
| エラー表示 | 条件付き | 無効入力や保存データ異常時の案内 |

## 2. ToDo アイテム表示契約

各 ToDo アイテムは最低限以下を表示する。

| 項目 | 表示内容 |
|------|----------|
| タスク名 | ユーザーが入力した内容 |
| 完了状態 | チェックボックスまたは同等のセマンティック操作要素 |
| 登録日時 | `YYYY/MM/DD HH:SS` 形式 |
| 削除操作 | ボタン要素 |

## 3. 操作契約

### タスク追加

- 有効なタスク名を送信した場合、新規 ToDo を一覧末尾へ追加する。
- 新規 ToDo は未完了状態で作成する。
- 追加直後に登録日時を表示する。
- 無効入力の場合は追加せず、利用者に修正を促す。

### 完了切替

- 対象 ToDo ごとに完了と未完了を切り替えられる。
- 切替結果は即座に画面へ反映し、保存状態にも反映する。
- 完了状態は色だけでなくテキストや装飾でも判別可能にする。

### 削除

- 削除操作後、対象 ToDo は一覧から除去される。
- 再読み込み後も削除済み ToDo は復元されない。

### フィルタ切替

- `すべて`、`未完了`、`完了済み` の 3 種を切り替えられる。
- 現在選択中のフィルタを視覚的に判別できる。
- フィルタに一致する ToDo がない場合は空状態表示を行う。

## 4. アクセシビリティ契約

- すべての操作要素はキーボードで到達可能であること。
- 入力欄、ボタン、チェックボックス、フィルタ操作はアクセシブルな名前を持つこと。
- フォーカス時の視認性を確保すること。
- エラーや完了状態は色だけで伝えないこと。

## 5. 永続化契約

- タスク内容、完了状態、登録日時は再読み込み後も復元されること。
- 保存データが壊れている場合は画面を壊さず、安全な初期状態で利用継続できること。
