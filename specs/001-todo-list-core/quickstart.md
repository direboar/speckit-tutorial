# クイックスタート: ToDoリスト基本機能

## 前提

- Node.js 22 系と npm を利用できること
- モダンブラウザを利用できること

## セットアップ

1. 依存関係を導入する。

```bash
npm install
```

2. 開発サーバーを起動する。

```bash
npm run dev
```

3. ブラウザでアプリを開き、初期画面が表示されることを確認する。

## 実装確認

1. タスク名を入力して追加する。
2. 追加直後にタスクが一覧へ表示され、登録日時が `YYYY/MM/DD HH:SS` 形式で見えることを確認する。
3. タスクの完了切替と未完了切替ができることを確認する。
4. タスク削除後、一覧と保存状態から除去されることを確認する。
5. フィルタを `すべて`、`未完了`、`完了済み` で切り替え、表示対象が変わることを確認する。
6. ページ再読み込み後もタスク内容、完了状態、登録日時、必要に応じてフィルタ状態が保持されることを確認する。

## 単体テスト

```bash
npm run test:unit
```

確認対象:

- 入力検証
- 登録日時の整形
- フィルタ判定
- `localStorage` への保存と復元
- 破損データ時の安全な初期化

## E2E テスト

```bash
npm run test:e2e
```

確認対象:

- タスク追加
- 完了切替
- タスク削除
- フィルタ切替
- 再読み込み後の状態維持

## リリース前手動確認

- モバイル幅とデスクトップ幅で横スクロールが発生しない
- キーボードだけで主要操作に到達できる
- フォーカスが視認できる
- 完了状態やエラーが色だけに依存していない
